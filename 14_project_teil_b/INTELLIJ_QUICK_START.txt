# IntelliJ Quick Start (2 minutes)

## 🚀 30-Second Setup

1. **Open IntelliJ**
   - File → Open → `/home/isc-den/cas-artificial-intelligence/14_project_teil_b`

2. **Set Python Interpreter**
   - Settings → Project → Python Interpreter → ⚙️ → Add
   - Select existing Python (any recent version works)
   - OK

3. **Install Dependencies**
   ```bash
   pip install torch gymnasium yfinance numpy pandas matplotlib
   ```

4. **Run the Script**
   - Right-click: `03_Working_Script.py`
   - Select: "Run '03_Working_Script.py'"

5. **Wait 30-60 minutes**
   - Watch the Run console for progress
   - You'll see the results comparison at the end

## 📍 That's it!

The script will:
- ✅ Download Bitcoin data
- ✅ Train forecasting model
- ✅ Train 2 PPO agents (with/without forecast)
- ✅ Evaluate both
- ✅ Show comparison table
- ✅ Save results to CSV

## ⚡ If It's Slow

Edit `03_Working_Script.py` line ~38-39:

```python
TOTAL_UPDATES = 50      # Faster (was 100)
TOTAL_EPISODES = 3      # Quicker (was 5)
```

Then run again. Takes ~15 minutes instead of 45.

---

## 🐛 If Something's Wrong

**Error: "No module named 'torch'"**
```bash
pip install torch
```

**Error: "No module named 'trading_env'"**
- Make sure you opened the right folder
- Should be: `/14_project_teil_b` not `/13_project_teil_b`

**Error: "CUDA out of memory"**
- Just close other apps
- Or edit script to use CPU (change line ~29)

**Script runs but stuck?**
- Check GPU (run `nvidia-smi` in terminal)
- Or check internet (yfinance download)
